Database Backup / Export

Downloads one JSON file containing all shared office data (Users, Bill Register, Daily Case Management, Gallery photo records, Team Chat). Documents/photos themselves stay on Cloudinary — this file has their links, not the actual files.

Restore from Backup File

Only use this if you know exactly what you are doing. Restoring replaces shared online data for everyone with the contents of the file you choose.

  1. Choose a previously downloaded backup (.json) file below.
  2. The system checks the file is a genuine backup file, and refuses it with a clear message if not.
  3. Before restoring, the system automatically takes a fresh "safety" backup of the current data first, in case the wrong file was chosen.
  4. When restore finishes, a confirmation message appears and it is recorded in the backup log.
This will replace ALL current shared online data with this backup file. This cannot be undone. A safety backup of the current data will be taken automatically first. Continue?
